Describes a 3d space in a Minecraft world using one of:

  • a starting point and size. The starting point can be any vertex or the middle of one of the horizontal faces, using the cardinal terminology defined in Anchor3.

  • two opposite corners

mcwb.get_block(client: Client, pos: Vec3) → Item[source]#

Get the block at the given position.

Uses loot spawn <dump> mine <pos>, which reports the loot table of the block, i.e. minecraft:blocks/<id>. Blocks without a loot table such as air, water or bedrock are identified from the error message instead.

Some blocks share the loot table of a related block, e.g. a wall torch reads back as a torch and a wall sign as a sign.

Raises ValueError if the position is not loaded or the server reports a block identifier that is not in Item (i.e. one added after MINECRAFT_VERSION).
